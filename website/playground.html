How to use the Playground

  • Paste Markdown, JSON, or plain text in the left panel
  • Select the input format using the buttons above the input
  • The SLIM output appears on the right in real time
  • Upload a file with the 📂 button (supports .md .json .txt)
  • Drag and drop a file anywhere on the window
  • Use Ctrl+Enter to force a refresh
  • Token counts use an approximation (1 token ≈ 4 chars)
